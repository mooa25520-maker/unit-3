أمن المعلومات 1 — التهديدات الأساسية

مفهوم أمن المعلومات

التعريف: أمن المعلومات هو عملية إدارة المعلومات بطريقة صحيحة والحفاظ عليها من الوصول غير المصرح به أو التعديل أو التدمير أو فقدان إمكانية الوصول إليها.

مثال: لو عندك درجات الطلاب على الكمبيوتر، لازم الشخص المسموح له فقط يشوفها، ومحدش يغيرها، وتفضل موجودة عندما تحتاج إليها.

العناصر الثلاثة لأمن المعلومات

CIA Triad

Confidentiality — السرية

المعلومات يشوفها الأشخاص المصرح لهم فقط.

مثال: درجات الطلاب لا يراها إلا الأشخاص المصرح لهم.

Integrity — السلامة/التكامل

المعلومات تظل صحيحة ولم يتم تغييرها أو العبث بها أو حذفها بطريقة غير مصرح بها.

مثال: 18/20 أصبحت 20/20 بدون تصريح.

Availability — التوافرية

المعلومات أو النظام يكون متاحًا عندما نحتاج إليه.

مثال: موقع النتائج توقف وقت إعلان النتائج بسبب هجوم إلكتروني.

العنصر معناه مثال للمشكلة
Confidentiality مين مسموح له يشوف؟ تسريب كلمة السر
Integrity هل البيانات صحيحة؟ تغيير درجة طالب
Availability هل أستطيع الوصول؟ توقف الموقع
تلميح للحفظ: تذكّر الحروف "CIA"

الوصول غير المصرح به — Unauthorized Access

هو الدخول إلى نظام أو جهاز بدون الحصول على إذن.

مثال: طالب يعرف Username وPassword المدرس ويدخل إلى النظام بدون إذن.

Cracking

الوصول غير القانوني للنظام بهدف:

  • التلاعب بالبيانات
  • حذف البيانات
  • سرقة البيانات

والشخص الذي يقوم بذلك يسمى Cracker.

البرمجيات الخبيثة — Malware

برامج مصممة لإلحاق الضرر بالكمبيوتر أو سرقة البيانات أو تنفيذ عمليات غير مرغوبة.

طرق الإصابة الشائعة:

مواقع الويب مرفقات البريد USB الشبكات

Virus مقابل Worm

الـ Virus يحتاج ملف مضيف أو تدخل من المستخدم لينتشر، بينما الـ Worm ينسخ نفسه وينتشر عبر الشبكات من تلقاء نفسه دون الحاجة لملف مضيف.

Malware ماذا يفعل؟

Cybercrime

أفعال إجرامية يتم ارتكابها باستخدام الكمبيوتر أو الشبكات، وتنقسم إلى:

1. انتهاك قانون الوصول غير المصرح به

مثال: الدخول إلى حساب شخص آخر بدون إذنه.

2. جرائم تتضمن الكمبيوتر أو السجلات الإلكترونية

مثال: تزوير سجلات إلكترونية أو تعديل بيانات مالية.

3. جرائم قائمة على الشبكة

مثال: نشر برمجيات خبيثة أو شن هجمات عبر الإنترنت.

كلمات المرور والمصادقة

Password

كلمة المرور هي سلسلة من الحروف والأرقام والرموز يستخدمها المستخدم لإثبات هويته والدخول إلى حساب أو نظام معين.

افعل

  • استخدم كلمة مرور طويلة
  • امزج بين Capital + Small + Numbers + Symbols
  • استخدم كلمة مرور مختلفة لكل حساب

لا تفعل

  • لا تستخدم معلوماتك الشخصية (اسمك، تاريخ ميلادك)
  • لا تعيد استخدام نفس كلمة المرور في أكثر من موقع
  • لا تشارك كلمة مرورك مع أي شخص

OTP — One-Time Password

كلمة مرور تُستخدم مرة واحدة فقط أو لفترة زمنية محدودة، وتصبح غير صالحة بعد الاستخدام أو انتهاء المدة.

482913 صالحة لدقائق فقط

Authentication

المصادقة: عملية التحقق من هوية المستخدم قبل السماح له بالوصول إلى نظام أو معلومة.

Knowledge-based

شيء تعرفه

Password، PIN، Security Question

Possession-based

شيء تمتلكه

Phone، Smart Card، OTP، SMS Code

Biometric

خصائص جسدية أو سلوكية

Fingerprint، Iris، Vein Pattern

Two-Factor Authentication (2FA) و Two-Step Authentication

2FA: استخدام عاملين مختلفين من عوامل المصادقة معًا.

مثال: Password (Knowledge) + SMS Code (Possession) = عاملان مختلفان

Two-Step: خطوتان للتحقق، لكن باستخدام معلومات من نفس نوع العامل.

مثال: Password + Security Question = كلاهما Knowledge

إجراءات الحماية

Access Control

تحديد من يستطيع الوصول إلى ماذا داخل النظام.

Teacher ← درجات الطلاب

Student ← درجاته فقط

Admin ← صلاحيات إدارية كاملة

Firewall

يعمل كحارس على بوابة الشبكة، ويساعد في منع الوصول غير المصرح به والتحكم في حركة البيانات الداخلة والخارجة.

Antivirus

يعمل من خلال:

Detection ← Isolation ← Removal، مع Updates مستمرة لقاعدة بياناته.

Security Updates

تصحح الثغرات الأمنية (Security Vulnerabilities) التي قد يستغلها المهاجمون قبل تحديث النظام.

Backup

نسخ احتياطي للبيانات يسمح باستعادتها في حال فقدانها أو تلفها. مثال: نسخ احتياطي دوري لملفات الطلاب لضمان استرجاعها عند أي عطل أو هجوم Ransomware.

الدرس الثالث

الاحتيال والحصول غير المصرح به على المعلومات

Fraudulent Billing

إرسال فواتير وهمية لخدمات لم يطلبها المستخدم بهدف خداعه ودفعه للدفع.

مثال: رسالة تفيد بوجود اشتراك غير مدفوع في خدمة لم يشترك بها المستخدم أصلًا، مع طلب الدفع الفوري.

One-click Fraud

User clicks URL
Fake contract
Payment request

بمجرد ضغطة واحدة على رابط، يظهر للمستخدم أنه وافق على عقد وهمي، ثم يُطالب بدفع مبلغ مالي فورًا.

Phishing

إرسال رسائل أو إنشاء مواقع مزيفة تنتحل صفة جهة موثوقة (بنك، شركة) لخداع المستخدم وسرقة بياناته.

رسالة مشبوهة

From: Fake Bank <support@fake-bank-security.com>

Subject: Your account has been suspended

Your account needs verification.
Click here to verify your account.

الرسالة مزيفة رغم أنها تبدو رسمية.

الرابط قد يقود إلى موقع مزيف يشبه الموقع الأصلي.

الهدف سرقة Password أو PIN أو بيانات البطاقة (Card Data).

Social Engineering

المهاجم لا يخترق الكمبيوتر... أحيانًا يخدع الإنسان.

الهندسة الاجتماعية هي التلاعب النفسي بالأشخاص لدفعهم للكشف عن معلومات سرية أو القيام بأفعال تضر بأمن المعلومات.

Impersonation

التظاهر بأنه شخص آخر لكسب الثقة.

مثال: شخص يتصل ويدعي أنه موظف من قسم IT.

Shoulder Surfing

مراقبة الشخص أثناء كتابة PIN أو Password للحصول عليها.

Dumpster Diving

البحث في القمامة عن أوراق أو معلومات سرية مُلقاة دون إتلاف.

Skimming

سرقة بيانات بطاقة الائتمان أو الخصم باستخدام جهاز غير قانوني (Skimmer) يُركّب على نقاط البيع أو أجهزة الصراف، ثم استخدام هذه البيانات بشكل احتيالي.

مثال: جهاز صغير مثبت داخل فتحة كرت الصراف الآلي يقوم بنسخ بيانات البطاقة أثناء الاستخدام العادي دون أن يلاحظ المستخدم.
